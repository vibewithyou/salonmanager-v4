# 📲 **SalonManager – App zur digitalen Salonverwaltung & Buchung**

---

## 🧩 **Ziel & Zweck der App**

**SalonManager** ist eine webbasierte, mobilfähige All-in-One-App für Friseursalons, Barbershops und Beauty-Studios.
Sie ermöglicht:

* Online-Terminbuchung durch Kund\:innen
* Verwaltung von Stylist\:innen, Diensten, Verfügbarkeiten
* Kundenbindung (Treuekarte, Galerie, Chat)
* Online-Zahlung & Rechnungssystem
* Newsletter, Marketing, KI-basierte Frisurvorschläge
* Admin- & Statistikanalyse

Die App funktioniert als **PWA** (installierbar wie eine App) und läuft auf PCs, Tablets und Smartphones.

# 📂 **Ordnerstruktur (Laravel-basiert)**

```
/app/Http/Controllers/        // Controller: Salon, Buchung, Zahlung, Chat, Admin
/resources/views/             // Views: Startseite, Salonseiten, Kundenbereich
/public/                      // Assets: CSS, JS, Bilder
/routes/web.php               // Routen: Buchung, Salonwahl, Dashboard
/database/migrations/         // Tabellen: Salons, Nutzer, Termine, Zahlungen, Chat etc.
```
